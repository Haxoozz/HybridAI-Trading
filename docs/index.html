System Design

Hybrid Architecture

ML signals are subordinate to deterministic safety gates. The system is fail-closed by default — if any gate cannot confirm safety, the trade is rejected.

🧠

LLM Oracle Swarm

8-model consensus engine (6 NVIDIA NIM + 2 HuggingFace). K-of-N majority vote with configurable quorum. Each model independently analyzes market context and returns a structured decision with confidence score.

quorum=3 · approvals=3 · timeout=15s · confidence_floor=0.60
🔒

RO-Lock

Risk-Outcome Lock. Deterministic execution gate validating every signal against risk/reward parity with slippage buffers. Minimum 2:1 R:R enforced.

Deterministic Gate
📉

STDAW Gate

Statistical Trend Deviation Adaptive Weighting. Exponentially suppresses signal confidence as volatility spikes beyond baseline norms.

Adaptive Filter
🛑

OOM-RL Halt

Circuit breaker at 10% global drawdown. Hard system stop preventing exploratory RL behavior outside the tested safety envelope. Requires manual rearm.

Circuit Breaker
📊

TSMOM Signal

Time-Series Momentum with 3-layer regime gate: ATR percentile rank → SMA200 trend → ADX>25 strength. 28-day momentum entry, 4H ATR stop sizing.

Capital Preservation

Fail-Closed by Default

The system is designed to reject trades when uncertain, not to find reasons to execute them.

🔴

10% Global Drawdown Halt

Hard circuit breaker triggers forced liquidation. Exists physically outside the ML agent's memory. Requires manual human intervention to un-halt.

🟡

2% Max Risk Per Trade

Position sizing enforced by ROLock gate with slippage buffers. No ML output can override this deterministic calculation.

🟢

Crash Recovery

SQLite-backed atomic state. 15/15 idempotency tests pass. Multi-bar outage recovery handles up to 12H downtime.

🔵

LLM Council Governance

No strategy change, risk parameter modification, or architectural decision proceeds without multi-model council deliberation and human ratification.

Cloud Integration

Anthropic API Usage

The Anthropic API serves as the premium reasoning fallback in the oracle chain. When the free-tier NIM/HuggingFace swarm cannot reach consensus, Claude provides the tiebreaking analysis with higher reasoning capability.

Oracle Fallback Chain

Mock Mode → NIM Swarm (6) → HF Router (2) → Anthropic Claude

Claude activates only when the 8-model free swarm fails to reach quorum — estimated <5% of cycles. This makes API usage highly efficient while preserving access to frontier reasoning when it matters.
